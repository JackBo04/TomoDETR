02 / THE IDEA

Predict points.
Let neighboring views talk.

The target is a set of particle centers. TomoDETR learns that representation directly from point annotations, then uses repeated observations from overlapping windows to improve each candidate.

01

Look locally

A 3D detector processes overlapping windows and predicts particle centers and classes with 64 spatial queries.

02

Connect across windows

The Cross-Window Query Refiner (CWQR) lets nearby candidates from different windows exchange information through sparse attention.

03

Refine together

Joint coordinate and class-score updates improve the candidate set before final selection.
